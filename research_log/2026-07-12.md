# Week 01 - Memory Feasibility Study

## Objectives

- Estimate VRAM requirements for the planned TSRT architecture.
- Verify whether selective fine-tuning of Qwen 1.7B is feasible on available hardware.

## Tasks Completed

- Loaded Qwen 1.7B successfully.
- Configured a simulation setup by unfreezing:
  - All attention modules.
  - The last 12 FFN layers.

- Executed a training test to monitor GPU memory consumption.

## Results

- Observed VRAM usage: approximately **16–18 GB**.
- The configuration was able to run without out-of-memory errors.
- Initial results suggest that partial fine-tuning of a Qwen 1.7B-based TSRT model is feasible on current hardware.

## Notes

- This experiment was conducted on a modified Qwen 1.7B setup to estimate resource requirements.
- The full TSRT architecture has not yet been implemented or benchmarked.
- Actual VRAM usage may differ after adding encoder-decoder structure, cross-attention modules, retrieval components, and multi-loss training.

## Next Steps

- Implement the TSRT architecture.
- Measure VRAM usage of the complete model.
- Begin HotpotQA fine-tuning experiments.
